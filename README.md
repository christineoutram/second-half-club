# The Second Half Club

Website for [secondhalf.club](https://secondhalf.club).

A community for women 40+ in the second half of life.

## Deployment

Hosted with GitHub Pages from the `main` branch, repository root.

## Files

- `index.html` — homepage
- `robots.txt` — search engine crawling rules
- `sitemap.xml` — sitemap
- `CNAME` — custom domain configuration
